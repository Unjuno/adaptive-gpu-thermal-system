# Documentation index

このディレクトリには、Adaptive GPU Thermal System の構想と今後の設計資料を保存する。

## 最初に読む文書

### 1. [`concept-master-ja.md`](concept-master-ja.md)

**日本語の構想基準文書。**

会話で確定した設計意図、重要な誤解の修正、冷媒ユニットの基本サイクル、GPU温度帯制御、海水・湖水利用、ロボット保守、既存流路での発電、排熱利用、未確定事項を保存している。

将来チャット履歴や外部コンテキストが失われた場合は、この文書をプロジェクト再開時の基準とする。

### 2. [`system-concept.md`](system-concept.md)

英語の初期技術概要。研究範囲、制御入力、運転モード、評価指標、安全上の論点、今後の工学作業を整理している。

## 文書の優先順位

文書間で内容が異なる場合、現段階では次の順序で解釈する。

1. `concept-master-ja.md` に記録された構想上の意図と境界
2. その後に明示的に承認された設計変更
3. `system-concept.md` 等の技術整理文書
4. README の短い概要

技術的な推測、一般的な冷却方式、既存製品の構成を、明示的な合意なしに本構想の確定仕様として扱わない。

## 現在の段階

現在のリポジトリは、構想の保存段階である。

具体的な冷媒、圧力、温度、寸法、流量、弁構成、熱交換器、発電量、養殖対象等は確定していない。これらは将来、設計・シミュレーション・実験へ進む場合に追加する。
