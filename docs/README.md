## Documentation policy

- 確定した構想と技術的推測を区別する。
- 未確定の冷媒、圧力、温度、寸法、流量を推測で仕様化しない。
- 性能、効率、安全性、経済性は検証結果が得られるまで断定しない。
- 設計変更は、変更理由と影響範囲を記録する。
- 失敗した試験や否定的な結果も記録対象とする。
